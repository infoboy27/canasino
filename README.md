# Canasino

Canasino is an on-chain gaming network built on the Canopy ecosystem, designed for transparent, verifiable and community-driven casino experiences.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Brand

- Primary gold: `#D4AF37`
- Canopy green: `#00C853`
- Background: `#050805`
- Token: `CASN`
- Tagline: `Play. Win. On-chain.`
