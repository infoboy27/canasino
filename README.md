# Canasino

Canasino is an on-chain gaming network built on the Canopy ecosystem, designed for transparent, verifiable and community-driven casino experiences.

## Product direction

The UI is intentionally designed as a **casino product first**, not a generic Web3 landing page. The lobby architecture takes proven interaction patterns from leading crypto casinos—fast access to Originals, category filtering, search, activity feeds, rewards/VIP and visible fairness tooling—while giving Canasino its own premium gold/Canopy-green identity and a stronger on-chain transparency layer.

### Core differentiators

- Canasino Originals as the primary acquisition and retention surface
- Provably-fair verification surfaced directly in the product UI
- On-chain settlement/proof links as a first-class experience
- CASN-native rewards and VIP progression
- Casino lobby UX optimized for desktop and mobile
- Honest pre-launch states: no fake balances, bets or wallet connections

## Current UI

- Premium crypto-casino lobby
- Left navigation rail on desktop
- Mobile bottom navigation
- Search and game category filtering
- Originals: Crash, Mines, Plinko, Dice, Roulette, Blackjack, Poker, Bingo, Limbo and Coin Flip
- Activity feed shell for Recent Bets / High Rollers / Lucky Wins
- Round Verifier interface
- CASN Club / rewards presentation
- Chain parameters and tokenomics
- Wallet integration modal ready for production connector
- 18+ / responsible play messaging
